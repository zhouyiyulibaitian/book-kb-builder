# 分类：怎么把一本设计书放进合适的类别

类别是知识库的一级目录，直接决定以后找不找得到这本书。分类只有两条要求：
**有依据**、**与已有类别保持一致**。

## 分类依据必须来自书本身

判断一本书属于哪一类，只能看这些证据：

- 书名与副标题（最直接的信号）
- 目录 / 章节结构（比书名更准：看它讨论什么主题、按什么线索组织）
- 前言 / 序 / 导论里作者的自我定位（作者会说明这本书属于哪个领域、写给谁看）
- 版权页 / 丛书信息（很多设计书属于某套丛书，丛书名往往就是类别）
- 出版社与丛书方向（如建筑工业出版社、设计类出版社的专门书系）
- 关键词、术语分布

**依据要写进总结的「类别」字段旁边**，例如：

```
类别：建筑与园林设计/中国园林史
分类依据：书名含"园林史"；目录按朝代分期组织；前言说明以园林形态的历史演变为纲
```

不要凭"感觉像"来分。设计学科边界本来就模糊，凭感觉分类会导致同一类书散落在三个地方。

## 先看已有类别，再决定是否新建

**这是最重要的一条**：分类前必须先读知识库已有的类别。

```bash
python scripts/kbtool.py list --kb-root 知识库        # 列出全部图书与类别
python scripts/kbtool.py plan --kb-root 知识库 --category X --title Y   # 看是否会新建类别
```

- 已有类别里**有合适的** → 直接归入，绝不新建。
- 已有类别里**有接近的** → 优先归入接近的，并在总结里写清它的secondary标签。
  例如《字体设计手册》在已有「视觉传达与平面设计」时，就归入该类，
  不要另建「字体设计」这个只放一本书的类别。
- 已有类别里**确实没有合适的** → 新建，且用下面的标准名称，不要自创同义词。

类别数量少而清晰，比多而琐碎有用得多。**只有当一类能装下 2 本以上书时才值得新建。**

## 设计类别的建议分类（参考，不是强制）

按国内设计学科的常见划法组织。斜杠表示可选的下级细分，只有在书多时才用：

**设计理论与历史**
- 设计史 / 设计理论 / 设计批评 / 设计思潮与运动（包豪斯、现代主义等）

**视觉传达与平面设计**
- 字体与排版 / 版式与网格 / 标志与品牌 / 包装设计 / 海报与招贴 / 书籍装帧 / 信息图表

**色彩**
- 色彩理论 / 色彩心理 / 色彩管理

**建筑与环境设计**
- 建筑史与理论 / 建筑设计方法 / 室内设计 / 景观与园林 / 城市设计 / 营造与构造技术

**工业与产品设计**
- 产品设计方法 / 人机工程学 / 材料与工艺 / 结构设计

**数字与交互设计**
- 交互设计 / 用户体验研究 / 用户界面 / 可用性测试 / 动效设计 / 游戏设计 / 服务设计

**设计基础与跨学科**
- 设计素描与构成 / 设计心理学 / 设计研究方法 / 设计管理与商业 / 设计教育与教学

**相邻学科（设计类研究中常需要，按需建类）**
- 美术与绘画 / 摄影 / 工艺美术与非遗 / 美学与艺术哲学 / 认知科学与人因

用法：
- 书名/内容明确属于某一子类且该子类已有 2 本以上 → 用两级，如 `视觉传达与平面设计/字体与排版`
- 否则只用一级，如 `视觉传达与平面设计`
- 拿不准用哪一级 → 用一级，宁可粗不要错

## 一书的标签与主类别

一本书只放一个目录（避免同一本书出现两份、日后改了一份另一份过期），
但可以在总结里给它若干关键词标签。跨领域的书这样处理：

```
类别：视觉传达与平面设计
关键词：版式；网格；现代主义；瑞士设计；设计教育
跨领域标签：设计史；设计理论
```

这样以后按 `设计史` 检索也能找到它，而文件只存一份。

## 命名要与用户已有习惯一致

如果用户的知识库已经用了某种命名（比如已经存在「平面设计」这个类别），
**沿用用户的说法**，不要改成你自己觉得更标准的「视觉传达与平面设计」。
一致性比正确性重要：两个近义类别并存，等于把书藏起来。

## 落盘前先预演

```bash
python scripts/kbtool.py plan --kb-root <知识库> --category <类别> --title <书名>
```

`plan` 会打印将创建的路径、以及知识库现有规模与已有类别。
先看一眼，确认没有误建重复类别，再正式 `build`。

## 分类结果要告知用户

分类是有主观性的决定，做完要明确说出来，方便用户纠正：

> 我把《字体设计手册》归入了「视觉传达与平面设计/字体与排版」，
> 依据是目录以字体结构与排版规则为主、前言说明面向平面设计师。
> 你的知识库里已有一级类别「视觉传达与平面设计」，所以没有另建「字体设计」。
> 想调整的话告诉我目标类别，`kbtool.py` 重新落库即可。
